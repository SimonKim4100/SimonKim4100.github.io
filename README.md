# simonkim4100.github.io

Source of Semin Kim's personal website: https://simonkim4100.github.io/

Built with [al-folio](https://github.com/alshedivat/al-folio) (MIT License), a Jekyll theme for academic websites.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000/.

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to the `gh-pages` branch.
